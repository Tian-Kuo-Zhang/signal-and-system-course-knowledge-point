## 内容

- **第一章：信号与系统基础** — 30 个知识点、11 组交互图。

- **第四章：连续时间傅里叶变换** — 114 个正文小节整理为 53 个精讲单元，22 组交互实验，12 道即时反馈自测，另含书面自测与详解。

## 怎样使用

1. **手机或电脑在线阅读**：打开上方“在线阅读”，无需登录和安装。
2. **完整离线阅读**：到 Releases 下载阅读包，解压后打开 `index.html`。
3. **只读一章**：单独保存 `chapter-1.html` 至 `chapter-4.html` 中对应的文件即可。正文、公式、图片、样式和动画已内嵌，无需 `assets` 或服务器。
4. **跨章跳转**：需要整套文件放在一起，保持文件名不变。

手机上下载 HTML 后，请用支持本地 HTML 和 JavaScript 的浏览器打开。聊天软件的文件预览可能禁用动画；直接访问在线阅读地址通常更方便。第四章公式使用 MathML，较旧的浏览器可能需要更新。长公式可在自己的区域横向滑动。

动画默认暂停，可播放、单步或重置；切换章节会停止动画。已读进度仅保存在当前浏览器，不会跨设备同步。
