 阅读方法

1. 下载并解压整个离线包，打开 index.html。
2. 只读单章，可以只发送对应 chapter-N.html，或本地的“第N章完整精讲.html”。
3. 目录支持知识点跳转；第五至八章还支持正文搜索。可播放参数变化、单步和重置，切换页自动停止动画。
4. 公式使用本地样式或原生 MathML，不依赖外部网站。手机请用较新浏览器，避免聊天软件静态预览。
5. 自评掌握进度只保存在当前浏览器。有限求和或显示窗口的实验均有说明。

 文件与来源

index.html 是八章入口；chapter-1.html 至 chapter-8.html 为阅读文件；版本清单.json 提供 SHA-256。无需安装、服务器或构建命令。
