打开 index.html 选择章节，也可以独立打开 chapter-1.html 至 chapter-4.html。
每章 HTML 都是完整的离线文件：正文、公式、图片、分页、交互动画、自测全部内嵌，不需要安装、构建或联网。

内容
第一章：信号与系统基础，30 个知识点、11 组交互图。
第二章：LTI 系统，26 个知识点、10 组交互图。
第三章：傅里叶级数，24 个知识点、9 组交互图。
第四章：连续时间傅里叶变换，53 个精讲单元、22 组交互实验、12 道即时反馈题，以及书面自测与详解。
第四章正文按 122 页课程课件范围整理，覆盖性质、系统、调制解调、LCCDE、部分分式与综合题；页码索引和课件笔误说明在章末。

下载与手机阅读
1. 下载整个文件夹或 ZIP 并解压，打开 index.html。
2. 只读一章时，只保存相应 chapter-N.html 即可；跨章跳转则需整包。
3. 在 GitHub 文件列表中点击 HTML 可能看到源码，这不是文件损坏。请下载文件后用浏览器打开。文件名前后不要额外增加 .txt。
4. 手机先保存到本地，用支持本地 HTML 和 JavaScript 的浏览器打开。部分聊天软件/文件管理器预览禁用脚本，可能无法翻页或播放动画。
5. 第四章公式采用 MathML，建议使用较新的浏览器。长公式可横向滑动，正文无需整页横向移动。
6. 书签（URL # 后的章节位置）可分享；已读进度只尝试保存在当前浏览器，不会跨设备同步。
