下载后如何使用

把整个文件夹下载并解压，打开 index.html（本地课程入口为“学习入口.html”）。也可以只保存某一章 HTML：图文、公式和动画均已内嵌，无需 assets、服务器或联网。跨章跳转需要其余章节文件在同一套目录中。

手机上先下载到本地，再用支持运行本地 HTML 与 JavaScript 的浏览器打开。聊天软件的文件预览可能不运行动画；第四章复杂公式使用浏览器原生 MathML，较旧浏览器可尝试更新或换一个浏览器。
